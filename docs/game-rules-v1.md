# 《芯片外交》可实现游戏规则 V1.0

> 定位：四方、不完全信息、以谈判为核心的回合制策略游戏。数值与政策效果均为**假设性游戏规则**，不构成现实政策预测。

## 1. 游戏目标与信息边界

- 角色：美国政府（US）、中国政府（CN）、荷兰政府（NL）、ASML（AS）。玩家选择其中一方，其余由 LLM Agent 扮演。
- 全局共 **4 回合**。每回合按「谈判 → 签约 → 同时秘密选行动 → 统一结算 → 公开结果」推进。
- 每方开局从自己的两张目标卡中**等概率随机获得一张私人目标卡**。该角色有哪些*可能的*目标卡公开，实际抽到哪张、具体目标及 Agent 的策略判断保密。
- 游戏规则、行动效果、公开状态和上轮实际行动对所有人可见；私聊只对参与者可见；任何 Agent（包括秘书）不得读取其他方的私人目标卡或私聊。
- **正式胜利**：第 4 回合结算后同时满足目标卡上的两个数值条件、本人至少参与过 **1 份全员履约的正式协议**、本人信用 ≥1。多人可同时获胜，也可能无人获胜。

## 2. 全局状态

全部指标取整数 **0～5**；初始值固定如下。数值是简化的游戏刻度，不是真实统计量。

| 字段 | 名称 | 初始 | 含义 |
|---|---|---:|---|
| `A` | 技术合作机会 | 3 | 中国取得**合法跨境技术合作**的可行程度；高则合作空间大 |
| `B` | 商业活力 | 3 | 四方相关半导体业务的整体商业环境；高则交易机会多 |
| `H` | 美荷协调 | 2 | 两国出口管制与产业政策的协调程度；高则更一致 |
| `R` | 中国自主技术 | 1 | 中国自主研发能力的长期积累；高则自主能力强 |

另外，四方各有 `credit=1`（信用，范围 0～2）、`fulfilledDeals=0`（已全员履约的协议数）。这两个值**公开**。

## 3. 桌外行动卡（每方每回合选 1 项）

`Δ` 表示对指标的增减；未列出的指标不变。各方均可额外选择 `PASS`（维持现状，效果 0）。

| 角色 | 行动 ID / 通俗名称 | 确定性效果或触发条件 |
|---|---|---|
| US | `U1` 收紧美国技术管制 | `A-1, B-1` |
| US | `U2` 有限放宽管制 | `A+1, B+1` |
| US | `U3` 与荷兰开展产业合作 | `B+1, H+1` |
| CN | `C1` 投资自主研发 | **下回合开始时** `R+1`；全局最多用 2 次，第 4 回合不可选 |
| CN | `C2` 限制关键材料出口 | `B-2`；用于形成供应链压力，但也损害总体商业环境 |
| CN | `C3` 提供市场合作便利 | `B+1` |
| NL | `N1` 收紧荷兰设备许可 | `A-1, B-1, H+1` |
| NL | `N2` 批准本轮有限许可 | `H-1`；仅当 AS 同轮选 `S1`，才产生对应订单效果 |
| NL | `N3` 提议美荷联合项目 | **仅当 US 同轮选 `U3`**，额外 `B+1, H+1`，否则无效果 |
| AS | `S1` 准备并执行对华合规订单 | 若 NL 同轮选 `N2`：`A+1, B+2`；否则**不交付**且 `B-1`（准备成本） |
| AS | `S2` 拓展其他市场 | `B+1, A-1`（商业分散但对华合作机会下降） |
| AS | `S3` 维护现有合规客户 | 若本回合**开始时** `A≥3`：`B+1`；否则无效果 |

**政策解释边界**：`U1/U2` 针对模拟情景中的美国管制范围；`N1/N2` 针对荷兰有权审批的、符合适用规则的设备。荷兰批准不代表可以突破美国适用禁令，ASML 也无权自行发放许可证。`A` 衡量的是剩余合法合作空间，不等于实际出口数量。

## 4. 谈判与协议

1. **自由声明**：每方每回合最多发出 **2 条谈判消息**（公开或定向私聊均计入）；每条消息建议不超过 100 字。消息只影响对方的判断，**不直接改变任何指标**。
2. **低输入成本**：玩家可只写关键词／一句话；点击「AI 润色」生成候选声明，修改或原样发送。润色不得添加玩家未表达的承诺、威胁或条件。也可直接发送原文。
3. **正式协议**：每方每回合最多发起 **1 份协议**；一份协议由 **2～4 方**参加，每位参加者须明确选择自己**本回合**承诺的一个**非 `PASS` 行动 ID**。发起者提交后，各被邀请方逐一点击接受／拒绝；全员接受才生效。
4. **签约限制**：每方每回合最多参加 **1 份生效协议**。生效后该方不可再加入其他协议；由后端在**最后一方接受时原子检查并锁定**全部签约者，若其中任何人已签别的协议，则此次签约失败。谈判阶段结束后，未获全员同意的提案失效。协议是**行动承诺**，不保证预定结果（例如荷兰批准后，ASML 仍可能不选择执行订单）。
5. **允许违约**：最终行动不强制与承诺相同。结算时，每个签约者若采取自己承诺的行动则 `credit+1`，否则 `credit-1`；信用截断在 0～2。**只有全体签约者都履约**，各签约者的 `fulfilledDeals+1`。
6. 私聊与口头承诺均**不产生协议效果**；未来回合条件、数量、价格等自由文本可供谈判，但 V1.0 **不作为可执行条款**，避免 AI 任意解释合同。

## 5. 精确结算顺序

1. **回合开始**：若上回合存在 `C1` 的待生效研发，本回合开始先执行 `R+1`，再向玩家显示最新状态；保存四项指标快照 `roundStart`。
2. **谈判/签约**：仅改变消息记录、协议签约状态；不改全局指标。
3. **秘密提交**：US、CN、NL、AS 各提交 1 个合法行动 ID，所有人提交后才结算；不能根据对方本轮已选行动临时反悔。
4. **计算增量**：以四方行动和 `roundStart` 为输入，按第 3 节规则计算各项增量（包括 `N2+S1`、`U3+N3` 两个联动规则）；**先合计，再更新**：`state[k] = clamp(roundStart[k] + ΣΔ[k], 0, 5)`。`C1` 只登记下回合待生效，不立即增加 `R`。
5. **核对协议**：按第 4 节更新签约者信用和履约记录，公布协议是否全员履行；没有签约的人信用不变。
6. **公开战报**：公布四方本轮实际行动、触发的联动条件、各项增量及最终状态；保留私人目标和私聊保密。第 4 回合末揭示各方目标并判定胜利。

**边界规则**：全部数值一次性合并后截断；`S3` 的资格看 `roundStart.A` 而不是本轮临时变化；非法行动或未成功提交不进入结算，必须重选或由后端以 `PASS` 超时兜底。服务器对同一回合只允许结算一次（幂等）。

## 6. 私人目标卡（每角色随机二选一）

所有目标以**第 4 回合结束后的数值**判断；每张卡均需满足第 1 节的协议与信用条件。

| 角色 | 类型 ID / 私人取向 | 两个胜利阈值 |
|---|---|---|
| US | `US_SEC` 安全优先 | `A≤2` 且 `B≥4` |
| US | `US_ALLY` 联盟优先 | `H≥4` 且 `A≤3` |
| CN | `CN_TECH` 自主突破 | `R≥3` 且 `A≥3` |
| CN | `CN_TRADE` 维持合作 | `A≥4` 且 `B≥4` |
| NL | `NL_ALLY` 协调优先 | `H≥4` 且 `B≥3` |
| NL | `NL_TRADE` 商业优先 | `A≥4` 且 `B≥4` |
| AS | `AS_CN` 对华业务 | `A≥4` 且 `B≥4` |
| AS | `AS_GLOBAL` 市场多元 | `B≥5` 且 `H≥3` |

**私人目标信息流**：目标仅发给对应角色的玩家或 Agent。其他人可以猜测，但不能读取实际目标。开局对玩家展示自己的目标、四项指标解释和行动卡；其他角色只展示公开利益介绍及可能目标类型。

## 7. AI 职责与实现边界

- **角色 Agent**：输入仅含本人的秘密目标、公开状态、公开消息、本人的私聊、本人当前协议和合法行动列表；输出**结构化**的 `message / accept|reject / actionId`，不得自创行动或改动数值。
- **秘书 Agent**：输入玩家自己的目标、公开信息及玩家亲历的私聊；输出「对方要求／可能动机／相关行动卡／对本方目标的风险」。推测需标为推测，不能读取他方隐藏信息。
- **规则引擎（非 LLM）**：负责行动合法性、协议有效性、全部数值变化、信用与胜利判定。LLM 只决定**说什么、接受什么、选哪个合法行动**。
- **会话**：后端保存 `state、round、goals(私有)、pendingResearch、researchUses、credit、fulfilledDeals、messages(带可见权限)、deals、actions、eventLog`。公开 API **不得返回**其他方的 `goals`、私聊或本轮尚未结算的行动；回合推进由后端调度，避免依赖浏览器保持打开。

## 8. 最小验收清单

- [ ] 同轮 NL=`N2`、AS=`S1` 时，AS 行动给 `A+1, B+2`；NL≠`N2` 时不给 `A`，且 `B-1`。
- [ ] 同轮 US=`U3`、NL=`N3` 时，在 US 的 `B+1,H+1` 外再增加 `B+1,H+1`。
- [ ] CN 第 1 轮选 `C1`：第 1 轮 `R` 不变，第 2 轮开始 `R+1`；第 4 轮不能选 `C1`。
- [ ] 同一回合多方增减先求和再截断到 0～5；重复结算不得重复加分。
- [ ] 签约后违约的实际行动仍生效，但本人 `credit-1`，协议不计入 `fulfilledDeals`。
- [ ] 不谈判可以行动、可以完成数值目标，但**不能获得正式胜利**；其他 Agent / 秘书不能读取不属于自己的隐藏信息。

**开发原则**：先固定本规则跑通 4 回合闭环；数值仅用于游戏内因果推演，不对政策效果作现实预测。后续调参应依据试玩数据，而非让 LLM 即兴修改规则。
