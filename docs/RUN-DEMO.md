# 芯片外交策略游戏运行与演示说明

## 作品定位

本作品是一款四回合、不完全信息的芯片外交策略游戏。玩家扮演美国、中国、荷兰或 ASML，在公开表态、闭门磋商、安排确认和实际行动中争取个人目标，并在第四回合结束后查看胜负、四轮复盘和完整博弈路径。

## 推荐演示方式

优先使用在线版本：

https://chip-diplomacy.app.workbuddy.host/?sharecode=3UW6RQU7HA

在线版本已经配置 DeepSeek，可直接开始完整对局。

## 本地运行

### 环境要求

- Node.js 22 或更高版本
- 近期版本的桌面浏览器
- 完整 AI 对局所需的 `DEEPSEEK_API_KEY`

本地包包含 `dist/`，因此无需运行 `npm install` 或重新构建。

### Windows

1. 解压压缩包。
2. 将 `.env.example` 复制为 `.env`。
3. 在 `.env` 中填写：

```text
DEEPSEEK_API_KEY=你的密钥
```

4. 双击 `start-windows.bat`。
5. 打开 `http://127.0.0.1:5001/`。

### macOS / Linux

```bash
cp .env.example .env
# 编辑 .env，填写 DEEPSEEK_API_KEY
sh start-mac-linux.sh
```

服务启动后打开 `http://127.0.0.1:5001/`。

## 建议演示流程

1. 展示三页背景导读，说明芯片产业链与四方利益关系。
2. 选择荷兰或 ASML，展示角色选择后的规则导读。
3. 逐页展示个人角色介绍、胜利条件、五阶段操作和右侧三个面板。
4. 创建对局，展示本局个人目标及其计分方式。
5. 完成一次公开表态，说明美国先发言和其他方可沉默。
6. 进入闭门磋商，发送一条消息并起草一份正式安排。
7. 在安排确认阶段展示发起方确认、受邀方接受或拒绝。
8. 进入实际行动，选择措施并展示两层预览：
   - 第一层为即时变化、不同情形、胜利进度范围。
   - 第二层为折叠的计算依据和措施对比。
9. 完成四轮对局，展示公开战报、四轮复盘和完整路径树。
10. 在最终结果页展示四方状态、AI 结局和外交胜利条件。

## 重点展示功能

- 四回合序贯行动：美国、荷兰、中国、ASML 依次决策。
- 公开表态、闭门磋商、安排确认、实际行动、公开战报五阶段。
- 正式安排的发起、确认、履约和违约信用机制。
- 个人目标、胜利进度、信用和外交胜利。
- 电讯、情报、幕僚三类辅助信息。
- 单轮完整博弈树和四轮行动路径复盘。
- 两层措施预览和本轮措施对比。
- 真实大模型生成回合摘要和赛后结局，失败时使用确定性模板。

## 常见问题

### 页面能打开，但“开始四回合博弈”不可用

检查 `.env` 中的 `DEEPSEEK_API_KEY` 是否已填写，并重启启动脚本。

### 端口 5001 被占用

关闭占用该端口的程序，或在 `.env` 中修改 `PORT`，再访问对应端口。

### 浏览器仍显示旧版本

使用强制刷新，或关闭旧标签页后重新打开链接。
