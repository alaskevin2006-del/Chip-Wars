# 不完全信息动态博弈：均衡分类检验与参数稳健性

## 1. 检验对象

对每个候选策略组合和信念系统，需要检验四件事：

1. 策略是否在每个信息集上序贯理性；
2. 路径上的信念是否符合贝叶斯更新；
3. 路径外的信念是否满足所选精炼条件；
4. 参数或模型结构变化后，均衡类别和结论是否改变。

第一项和第三项共同决定它是否构成 PBE。第四项属于稳健性分析，不是均衡存在性检验。

## 2. 分离、混同和半分离的操作定义

令：

- \(p(R\mid h)\) 为高类型发送限制信号 \(R\) 的概率；
- \(p(R\mid \ell)\) 为低类型发送限制信号 \(R\) 的概率；
- \(S_\theta=\{m:p(m\mid\theta)>0\}\) 为类型 \(\theta\) 使用的信号支持集。

### 2.1 纯分离

如果：

\[
p(R\mid h)=1,\qquad p(N\mid \ell)=1,
\]

或者：

\[
p(N\mid h)=1,\qquad p(R\mid \ell)=1,
\]

则两个类型选择不同信号，构成纯分离均衡。

### 2.2 分布分离

更一般地，只要不同信号的支持集不相交：

\[
S_h\cap S_\ell=\varnothing,
\]

观察信号就能完全识别类型，因此属于完全揭示信号的分离结果。即使某一类型在自己的信号集内部随机化，也不会造成类型混淆。

### 2.3 混同

如果两个类型使用完全相同的信号分布：

\[
p(\cdot\mid h)=p(\cdot\mid \ell),
\]

则构成混同均衡。

最常见的纯混同是：

\[
p(R\mid h)=p(R\mid \ell)=1,
\]

或：

\[
p(R\mid h)=p(R\mid \ell)=0.
\]

### 2.4 半分离

在两类型、两信号博弈中，典型半分离形式是：

\[
p(R\mid h)=1,
\]

\[
p(R\mid \ell)=q,\qquad
p(N\mid \ell)=1-q,\qquad
0<q<1.
\]

即高类型固定选择限制，低类型在限制和不限制之间随机化。

更一般地，半分离可定义为：

- 两种类型的信号分布不同；
- 至少一个共同信号会以正概率被两种类型发送；
- 至少一个类型在多个信号之间随机化。

### 2.5 用总变差距离编码

编程实现时，可以用两个信号分布的总变差距离：

\[
TV(P_h,P_\ell)
=
\frac{1}{2}
\sum_m
\left|
p(m\mid h)-p(m\mid\ell)
\right|.
\]

分类规则为：

| 距离 | 解释 |
|---|---|
| \(TV=0\) | 信号分布完全相同，混同 |
| \(0<TV<1\) | 有信号重叠但分布不同，半分离 |
| \(TV=1\) | 支持集不相交，完全揭示类型，分离 |

## 3. PBE 的逐项检验

### 3.1 贝叶斯信念更新

对任意均衡路径上以正概率出现的信号 \(m\)：

\[
\mu(\theta\mid m)
=
\frac{
p(\theta)p(m\mid\theta)
}{
\sum_{\theta'}
p(\theta')p(m\mid\theta')
}.
\]

如果某个信号在均衡路径上的总概率为零，则不能使用该公式，必须单独指定路径外信念。

### 3.2 序贯理性

对每个智能体 \(i\)、每个信息集 \(I_i\) 和每个可行动作 \(a_i\)：

\[
EU_i(
\sigma_i^*\mid I_i;\mu
)
\geq
EU_i(
a_i,\sigma_{-i}^*\mid I_i;\mu
).
\]

程序实现时需要允许一个小数值容差：

\[
EU_i(a_i^*)
\geq
EU_i(a_i)
-\varepsilon.
\]

建议同时记录每个信息集的收益差：

\[
\Delta_i(I_i,a_i)
=
EU_i(a_i^*(I_i))
-
EU_i(a_i).
\]

均衡要求所有 \(\Delta_i\geq0\)。最小的 \(\Delta_i\) 称为均衡的**稳健裕度**。

### 3.3 混合策略的额外条件

若某智能体在多个动作之间以正概率随机化，则这些动作的期望收益必须相等：

\[
EU_i(a_k)
=
EU_i(a_j),
\]

同时不能低于其他动作：

\[
EU_i(a_k)\geq EU_i(a_m)
\quad\forall m.
\]

否则随机化不构成最优反应。

### 3.4 路径外信念和精炼

PBE 对部分路径外信念没有唯一限制，因此可能出现：

- 同一策略组合在多种路径外信念下都成立；
- 某些混同均衡依靠特定路径外信念维持。

两类型、两信号模型中，路径外信号只有一个信念参数，可以在 \([0,1]\) 内完整扫描。更多类型时，需要：

- 扫描信念单纯形；
- 使用序列均衡的颤抖手构造；
- 使用直观标准、 divinity 等信号博弈精炼；
- 检查均衡是否依赖极端路径外信念。

如果某个均衡只在极端路径外信念下成立，应把它标记为“弱稳健”或“依赖精炼”。

## 4. 小规模模型的完整枚举算法

对于两类型、两信号、有限动作的模型，可以按以下步骤计算。

### 4.1 枚举纯信号模式

纯信号模式只有四种：

| 模式 | 高类型 | 低类型 | 初步分类 |
|---|---|---|---|
| \(RR\) | \(R\) | \(R\) | 混同 |
| \(RN\) | \(R\) | \(N\) | 分离 |
| \(NR\) | \(N\) | \(R\) | 分离 |
| \(NN\) | \(N\) | \(N\) | 混同 |

### 4.2 求解每个信号模式下的后续博弈

给定信号模式：

1. 用贝叶斯法则计算路径信念；
2. 从最后一个行动阶段向前求解；
3. 检查后续智能体在每个信息集上的最优反应；
4. 代回政府信号选择；
5. 检查政府类型是否存在偏离。

### 4.3 枚举半分离候选

例如高类型固定 \(R\)，低类型以概率 \(q\) 选择 \(R\)。则：

\[
\mu(h\mid R)
=
\frac{p}{p+(1-p)q},
\]

\[
\mu(h\mid N)=0.
\]

低类型必须有：

\[
EU_\ell(N)
=
EU_\ell(R).
\]

如果这个等式只在 \(q=0\) 或 \(q=1\) 时成立，则不存在内点半分离，只存在分离或混同。

如果两种类型都在多个信号间随机化，需要同时求解：

- 各类型对信号的混合概率；
- 各信号上的信念；
- 后续智能体的最优反应；
- 各类型混合时支持内动作的收益相等条件。

这是一个非线性互补问题。小规模可以用穷举支撑集或 Gambit 求解候选均衡，再人工检查 PBE 信念。

### 4.4 伪代码

```text
for 参数组合 in 参数空间:
    for 策略组合 in 候选策略组合:
        μ = 计算路径信念(策略组合)

        if 路径外信息集存在:
            for μ_off in 可行的路径外信念集合:
                if 所有信息集满足序贯理性:
                    记录均衡(策略组合, μ, μ_off)

        分类均衡(TV距离, 混合概率)
        记录最小收益裕度
```

## 5. 用前面的五智能体数值例子检验

收益顺序为：

\[
(u_U,u_C,u_T,u_A,u_B).
\]

### 5.1 分离候选

候选策略：

\[
h\to R,\qquad \ell\to N,
\]

\[
R\to a,\qquad N\to r,
\]

\[
R\to J,\qquad N\to K,
\]

\[
(A,B)\to(E,E).
\]

路径信念：

\[
\mu(h\mid R)=1,\qquad
\mu(h\mid N)=0.
\]

关键收益比较：

| 信息集 | 最优动作与偏离动作 | 收益差 |
|---|---|---:|
| \(I_R\) | \(a\) 对 \(r\) | \(3-1=2\) |
| \(I_N\) | \(r\) 对 \(a\) | \(5-2=3\) |
| \(I_{Ra}\) | \(J\) 对 \(K\) | \(4-2=2\) |
| \(I_{Rr}\) | \(J\) 对 \(K\) | \(5-1=4\) |
| \(I_{Na}\) | \(K\) 对 \(J\) | \(3-0=3\) |
| \(I_{Nr}\) | \(K\) 对 \(J\) | \(2-0=2\) |
| 高类型信号 | \(R\) 对 \(N\) | \(13-5=8\) |
| 低类型信号 | \(N\) 对 \(R\) | \(7-6=1\) |

所有收益差大于零，因此分离 PBE 成立。

最小稳健裕度是低类型的信号收益差：

\[
\Delta_{\min}=1.
\]

这说明该分离均衡的收益差不大。只要参数扰动使低类型选择 \(N\) 的收益下降超过 1，或者使选择 \(R\) 的收益上升超过 1，分离均衡就可能消失或改变。

### 5.2 混同 \(RR\) 候选

两个类型都选择 \(R\)。路径信念为：

\[
\mu(h\mid R)=0.5.
\]

在 \(R\) 后，中国政府选择 \(a\) 和 \(r\) 的阶段期望收益都是 1.5，可以混合。低类型在 \(R\) 路径上的最高收益为 4。

若低类型偏离到路径外的 \(N\)：

- 在 \(N\) 上中国政府始终选择 \(r\)；
- 第三方主体随后选择 \(K\)；
- 低类型偏离收益为：

\[
6-2+0+3=7.
\]

因为：

\[
7>6,
\]

低类型会偏离，所以纯混同 \(RR\) 不成立。

### 5.3 混同 \(NN\) 候选

两个类型都选择 \(N\)。中国政府选择 \(r\)，第三方主体选择 \(K\)。

高类型在 \(N\) 上的收益是 5。若高类型偏离到 \(R\)，无论路径外信念如何设定，其收益至少为：

\[
8-2+0+3=9.
\]

因为：

\[
9>5,
\]

高类型会偏离，所以纯混同 \(NN\) 不成立。

### 5.4 高类型固定 \(R\)、低类型混合的半分离候选

令：

\[
p(R\mid h)=1,
\]

\[
p(R\mid \ell)=q,\qquad 0<q<1.
\]

此时：

\[
\mu(h\mid N)=0.
\]

低类型在 \(N\) 上的收益为：

\[
EU_\ell(N)=7.
\]

在 \(R\) 上，可能导致的最大低类型收益为：

\[
EU_\ell(R)\leq6.
\]

因此：

\[
EU_\ell(N)>EU_\ell(R)
\]

对所有 \(0<q<1\) 成立。低类型没有随机化动机，混合概率会退化为 \(q=0\)。

所以该单边混合半分离候选不成立。

### 5.5 高类型混合、低类型固定 \(N\)

若高类型以正概率选择 \(R\)，低类型固定选择 \(N\)，则高类型选择 \(R\) 的收益为 13，选择 \(N\) 的收益为 5。

由于：

\[
13>5,
\]

高类型不会在 \(R\) 和 \(N\) 之间随机化。该候选也不成立。

在这个参数示例中，分离均衡成立，而上述纯混同和单边混合候选不成立。但不应把这项手工检查当作全局唯一性证明；完整结论仍需枚举所有支撑集或使用均衡求解器。

## 6. 参数敏感性分析

### 6.1 确定参数清单

建议区分四类参数：

| 类别 | 示例 |
|---|---|
| 信息参数 | 先验 \(p(h)\)、类型数量和类型分布 |
| 政策收益 | 限制的安全收益、反制成本、联盟收益、市场准入损失 |
| 企业参数 | 合规成本、迁移成本、替代速度、沉没资本、企业利润 |
| 第三方参数 | 安全依赖、市场依赖、战略自主价值和联盟外部性 |

本示例中应至少改变：

- \(p(h)\)；
- 高、低类型的限制收益；
- 反制给美国政府造成的损失；
- 第三方加入联盟给美国政府带来的收益；
- 中国政府在 \(R\) 和 \(N\) 后选择 \(a\) 或 \(r\) 的收益；
- 第三方选择 \(J\) 或 \(K\) 的收益；
- 企业 2×2 收益矩阵。

### 6.2 单参数敏感性

对每个参数 \(\theta_j\)：

1. 在合理区间内取网格；
2. 对每个点求所有候选 PBE；
3. 记录均衡类别、战略动作和收益；
4. 记录最小稳健裕度；
5. 用二分法寻找均衡类别发生变化的临界值。

例如，分离均衡的低类型条件可写成：

\[
\Delta_\ell
=
u_U(\ell,N,r,K)
-
u_U(\ell,R,a,J)
>0.
\]

当前 \(\Delta_\ell=1\)。对参数 \(x\) 做敏感性分析时，实际是求：

\[
\Delta_\ell(x)=0
\]

的临界点。在该点两侧，均衡类别可能发生变化。

### 6.3 双参数敏感性

选择两个最关键的参数，例如：

- 先验 \(p(h)\) 与低类型限制收益；
- 中国反制成本与企业合规成本；
- 第三方加入收益与市场损失。

在二维网格上分别求解 PBE，用不同颜色标注：

- 分离；
- 混同 \(RR\)；
- 混同 \(NN\)；
- 半分离；
- 多重均衡；
- 无纯策略 PBE。

这类图比单参数曲线更容易看出均衡区域和临界边界。

### 6.4 蒙特卡洛敏感性

为参数设定联合分布，例如：

\[
\theta
\sim
\text{Uniform}
\quad\text{或}\quad
\text{Beta}
\quad\text{或}\quad
\text{Lognormal}.
\]

每次抽样后完整求一次均衡，并统计：

- 分离、混同、半分离的出现频率；
- 各智能体策略动作的频率；
- 均衡收益的均值、中位数和 90% 分位区间；
- 多重均衡出现的频率；
- 最小收益裕度的分布。

不能只报告一个“基准均衡”的收益，还应报告均衡类别概率和收益区间。

### 6.5 全局敏感性

当参数较多时，可以使用：

- Morris 筛选：找出影响最大的参数；
- Sobol 指数：分解收益或均衡概率的方差来源；
- 回归或随机森林重要性：用于筛查，不替代理论解释。

均衡类别是离散变量，可以编码为：

\[
\mathbf{1}\{\text{分离}\},\quad
\mathbf{1}\{\text{混同}\},\quad
\mathbf{1}\{\text{半分离}\}
\]

然后对这些 0/1 变量做敏感性分析。

### 6.6 结构敏感性

参数稳健性不等于模型稳健性。还应改变模型结构：

| 结构变化 | 检验目的 |
|---|---|
| 2 个类型增加为 3 个类型 | 检验类型离散化是否改变结论 |
| 二元信号增加为多级管制强度 | 检验政策空间简化是否关键 |
| 同时行动改为顺序行动 | 检验行动时序的影响 |
| Cournot 改为 Bertrand | 检验产品市场竞争形式的影响 |
| 企业集合体拆成异质企业 | 检验加总是否掩盖关键异质性 |
| 企业完美信息改为私人信息 | 检验信息结构的影响 |
| 改变路径外信念精炼 | 检验均衡是否依赖特定信念 |
| 改变折现因子和期限 | 检验短期与长期结论 |

结构敏感性通常比单纯参数扰动更重要，因为它检验的是模型假设本身。

### 6.7 均衡选择的稳健性

如果同一参数下存在多个 PBE，不要随意选择一个报告。应：

1. 列出所有均衡及其策略；
2. 报告收益最低和最高均衡；
3. 比较均衡类别；
4. 使用明确的选择准则，例如收益占优、风险占优、历史拟合或直观标准；
5. 检验核心研究结论是否在所有均衡下都成立。

## 7. 推荐报告方式

建议至少报告以下内容：

| 项目 | 基准值 | 参数区间 | 均衡类别 | 最小收益裕度 | 结论 |
|---|---|---|---:|---|---|
| 高安全偏好政府限制 | \(R\) | 收益 \(8\pm25\%\) | 分离 | 8 | 稳定 |
| 低安全偏好政府不限制 | \(N\) | 收益 \(6\pm25\%\) | 分离 | 1 | 较脆弱 |
| 中国反制 | \(N\to r\) | 成本变化 | 分离 | 3 | 中等 |
| 第三方加入联盟 | \(R\to J\) | 收益变化 | 分离 | 2 | 较稳定 |

稳健性结论应写成：

> 在基准参数附近，分离均衡成立；但当低类型不限制收益下降超过 1，或限制收益上升超过 1 时，低类型会转向限制，分离均衡消失。因此“高类型限制、低类型不限制”的分离结论存在但边际较弱。

这比只报告“模型检验通过”更有信息量。
