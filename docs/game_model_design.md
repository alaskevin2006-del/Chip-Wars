# 半导体出口管制多智能体博弈：模型设定与项目参考

## 1. 总体判断

不建议把中国政府、中国企业、美国政府、美国企业、第三方政府和第三方企业直接放进一个同时行动的单层收益矩阵。更合适的做法是建立一个有限期、带持久私人类型的动态贝叶斯博弈，并在每个阶段嵌入三个子博弈：

1. 政府间不完全信息动态博弈；
2. 政府与本國企业之间的规制、筛选和委托代理博弈；
3. 企业之间的重复寡头竞争与供应链网络博弈；
4. 美国、中国与第三方政府之间的共同代理或竞争性影响博弈；
5. 第三方政府之间的联盟形成博弈。

建议的总体名称是：

> 多层动态贝叶斯 Stackelberg 博弈（multi-level dynamic Bayesian Stackelberg game），其中第三方层包含联盟形成外部性。

这不是一个已有标准教科书中单一命名的博弈，而是把若干标准博弈模型嵌套后形成的计算模型。理论基准可取完美贝叶斯均衡（PBE）；计算模型可先求小型有限博弈的精确或近似均衡，再用多智能体强化学习做大样本情景分析。

## 2. 参与者与私人信息

### 2.1 参与者

基线模型建议采用“国家政府 + 企业类型块”的表示方式，而不是一开始就放入成百上千家真实企业：

- \(G_{US}\)：美国政府；
- \(G_{CN}\)：中国政府；
- \(F_{US}\)：美国企业集合，可按 EDA、半导体设备、芯片设计、制造等类型拆分；
- \(F_{CN}\)：中国企业集合，可按设计、制造、设备、材料、终端需求等类型拆分；
- \(G_k\)：第三方政府，例如荷兰、日本、韩国，欧盟可作为联盟型主体单独建模；
- \(F_k\)：第三方企业集合，例如关键设备、代工、存储和材料企业类型。

企业“集合体”不应被无条件当作一个具有统一偏好的理性主体。若确实以行业协会或企业集团作为一个元主体，需要额外设定内部聚合规则，例如多数投票、游说竞争或代表性企业。更稳妥的基线是“若干企业类型 + 每类一个代表主体”，并在稳健性检验中拆成更多异质企业。

### 2.2 状态

令 \(s_t\) 表示第 \(t\) 期的公共状态：

- 技术能力、技术代差和国产替代进度；
- 企业对特定供应商、设备、材料或市场的暴露程度；
- 当前出口管制范围、许可证政策和执法强度；
- 供应链网络与已沉没的产能布局；
- 第三方政府的对齐状态或联盟结构；
- 国内政治压力和市场景气；
- 各方对私人类型的共同信念。

令 \(\theta_i\) 表示参与者 \(i\) 的持久私人类型。建议至少包含：

- \(G_{US}\)：安全偏好强度、对本国产业损失的敏感度、政策承诺可信度；
- \(G_{CN}\)：反制成本、技术替代紧迫性、升级或缓和偏好；
- 美国企业：对华收入依赖、合规成本、技术不可替代性、迁移成本；
- 中国企业：进口依赖、替代能力、受制裁风险、研发努力成本；
- 第三方政府：安全依赖、市场依赖、战略自主价值和国内政治约束；
- 第三方企业：管辖暴露、客户集中度、切换供应商成本、灰色地带收益。

### 2.3 行动

美国政府：

- 管制范围：窄口径、宽口径、分阶段扩围；
- 执法强度：低、中、高；
- 许可证：普遍拒绝、逐案审查、白名单；
- 联盟激励：安全承诺、补贴、市场准入、制裁威胁。

中国政府：

- 对等或非对等反制；
- 产业补贴、政府采购、信贷和研发支持；
- 供应链多元化与国产替代；
- 对外资企业的市场准入、合规审查或豁免；
- 公开信号与政策模糊性。

企业：

- 完全合规、申请许可证、产品重新设计；
- 更换供应商、迁址、调整客户结构；
- 继续交易、法律挑战、游说；
- 研发替代、库存、退出市场。

第三方政府：

- 跟随美国、对华对冲、战略自主、靠近中国；
- 参加或退出出口管制联盟；
- 向美国或中国索取补偿；
- 对本国企业实施宽严不同的许可和执法。

第三方企业：

- 按管辖地合规、多点布局、供应链重组；
- 继续供应、申请豁免、法律或政治游说；
- 退出某一市场或业务。

## 3. 各类博弈关系

### 3.1 美国政府与美国企业：规制型贝叶斯 Stackelberg 博弈

美国政府先选择管制范围、许可证规则、执法概率和处罚强度，本国企业观察到公开政策后作出合规、游说、重设计或迁移决策。

更精确地应拆成两个阶段：

- 政策形成阶段：企业和行业协会通过游说、信息提供和政治支持影响政府，属于影响活动或共同代理博弈；
- 政策执行阶段：政府公布规则后企业作出反应，属于规制型 Stackelberg 博弈。

若只研究已公布政策的执行效果，可以省略第一阶段；若研究管制范围为何扩大或收缩，则必须保留政策形成阶段。

该关系同时包含：

- 逆向选择：政府不知道企业的真实合规成本和供应链依赖；
- 道德风险：政府无法完全观察企业是否真实合规；
- 信号传递：企业通过投资、迁移、公开游说或供应链数据释放类型信号；
- 重复执法：企业会根据过去被审查和处罚的记录更新对执法强度的信念。

因此可写为：

> 带道德风险和不可完全观测合规行为的动态贝叶斯 Stackelberg 规制博弈。

政府可选择一组许可证和执法机制，而不是只选择一个管制强度。企业的激励相容约束为：

\[
U_i(\text{真实合规}\mid \theta_i,\text{政策})
\geq U_i(\text{规避或虚假申报}\mid \theta_i,\text{政策})
\]

参与约束表示企业不退出该市场或供应链。若企业类型连续，模型会迅速复杂化；第一版建议使用 2 至 3 个离散企业类型。

### 3.2 中国政府与中国企业：动态筛选—信号与委托代理博弈

中国政府选择补贴、政府采购、信贷、研发支持和合规要求。企业拥有关于自身技术能力、研发成本、替代速度和商业风险的私人信息，并可能通过研发投入或产能扩张向政府释放信号，以争取政策支持。

该关系适合写为：

> 含逆向选择和道德风险的动态委托代理/筛选—信号博弈。

其核心不是“政府命令企业”，而是：

- 政府希望企业承担战略任务，但不知道企业真实能力；
- 企业希望获得补贴或市场保护，可能夸大能力或隐藏成本；
- 政府无法完全观察研发努力；
- 企业可通过可观测投资向政府传递类型信号；
- 政策支持会影响企业后续退出、合谋或继续创新的激励。

若研究重点是政策工具选择，可把政府视为 Stackelberg 领导者；若研究重点是事前能力筛选，则应使用筛选模型，并把许可、补贴或采购合同视为机制。

### 3.3 中国企业与中国政府：战略服从与补偿性谈判

当企业需要承担与商业利益不一致的国家战略任务时，政府和企业还存在第二层关系：

- 政府要求供应安全、国产替代或对外反制；
- 企业要求补贴、采购承诺、融资或监管豁免作为补偿；
- 企业可能表面服从、实际延迟投资或向地方政府游说。

该关系可建模为重复关系契约或动态议价博弈。企业有退出选项时，应使用带外部选项的纳什议价或重复博弈；没有退出选项时，才适合使用单向委托代理。

### 3.4 美国企业与中国企业：重复贝叶斯寡头与供应链网络博弈

两国企业并不只服从政府，也在产品市场、技术标准和供应链上直接竞争或合作。

若研究对象是芯片、设备和材料的价格与产量，建议使用：

> 重复贝叶斯寡头博弈，阶段子博弈为差异化 Cournot 或 Bertrand 竞争。

若研究对象是供应商替换、关键节点控制和转口路径，建议使用：

> 带私人类型和网络外部性的供应链网络形成博弈。

企业的收益可写成：

\[
\Pi_i =
\text{产品市场利润}
- \text{合规成本}
- \text{供应链切换成本}
- \text{预期处罚}
+ \text{政府补贴}
+ \text{未来选择权价值}.
\]

这一层不应设为零和博弈。出口管制可能同时造成双方损失，也可能通过市场重组使某些第三方企业获益。

### 3.5 美国、中国与第三方政府：双委托人共同代理博弈

美国和中华人民共和国都可向第三方政府提供正向激励或施加负向压力：

- 美国提供安全承诺、技术合作、补贴或市场准入；
- 中国提供市场、投资、原材料或产业合作；
- 第三方政府选择对齐程度、管制参与程度和执法强度；
- 第三方政府的决策又受到本国企业和国内政治的约束。

可写为：

> 双委托人共同代理博弈，并叠加负向制裁和竞争性影响。

若美国和中华人民共和国通过“有条件利益输送”竞争第三方的政策，可采用菜单拍卖或共同代理模型；若主要手段是制裁和反制，可采用竞赛博弈或带外部选项的议价博弈。两者都嵌入政府间不完全信息动态博弈，而不是另起一个独立的静态博弈。

### 3.6 第三方政府之间：带外部性的联盟形成博弈

第三方政府之间不是简单的重复囚徒困境，因为一个国家的加入会改变其他国家的收益。典型外部性包括：

- 加入管制联盟会减少技术泄漏，但也可能把订单转移给未加入者；
- 越多的国家加入，联盟越有效，但单个国家搭便车的收益越高；
- 转口和供应链重组会使未加入者获益；
- 美国和中华人民共和国可能对不同成员给予不同补偿；
- 退出联盟会改变整个供应链和执法网络。

因此建议使用：

> 带联盟外部性的联盟形成博弈，或称分割函数博弈（partition-function game）。

第三方政府的收益取决于整个联盟结构 \(C\)，而不只是自己是否属于某个联盟：

\[
W_k = W_k(C;\theta_k,s_t).
\]

若允许成员之间转移支付，可以研究稳定联盟、核心或联盟结构稳定性；若不允许转移支付，应使用联盟证明纳什均衡或动态加入—退出博弈。不要只用 Shapley 值预测联盟，因为 Shapley 值是在给定联盟后分配收益，不能单独解决带外部性的联盟形成问题。

### 3.7 第三方政府与本国企业：两层博弈

第三方政府面对的是国内企业、盟友压力和本国选民的共同约束。适合写为：

> 国际谈判层 + 国内批准/企业游说层的两层博弈。

政府在国际层选择对齐程度，企业在国内层选择合规、迁移、游说或继续交易；政府再把企业反应纳入本国政治收益。对于 ASML、TSMC、三星等供应链关键节点，企业不是单纯的政策接受者，而具有退出、延迟投资和供应拒绝的议价能力。此时政府—企业关系应从 Stackelberg 跟随转为：

> 带外部选项的双边议价或共同决策博弈。

这会显著改变“政府先动、企业后动”的简单假设。

### 3.8 第三方企业之间的竞争与合规网络

第三方企业之间的互动可建模为：

> 多管辖地、重复、带私人合规成本的网络博弈。

企业选择供应商、客户、生产地和合规策略。其最佳反应依赖其他企业是否迁移、政府是否执法以及转口网络是否可用。若企业数量很多且理性程度有限，可使用多群体演化博弈；若企业数量少但战略性强，应使用贝叶斯纳什或动态博弈。

## 4. 推荐的整体结构

### 4.1 每期时序

建议采用季度为阶段、8 至 12 期为基准期限：

1. 自然抽取或更新各方类型，并实现外生技术冲击；
2. 美国和中国政府选择政策，第三方政府选择对齐或联盟行动；
3. 企业观察到公开政策信号，但不观察对方私人类型；
4. 企业选择合规、研发、迁移、供应和市场行动；
5. 市场出清，形成利润、贸易流、技术能力和政治成本；
6. 所有参与者根据公开结果更新信念；
7. 进入下一期。

第三方联盟结构可作为状态变量，通过加入、退出和重新谈判在期与期之间转移。

### 4.2 均衡概念

整体模型：

- 有限期完整模型使用完美贝叶斯均衡；
- 若状态转移和策略满足平稳性，可使用马尔可夫完美贝叶斯均衡；
- 若信号节点的信念不满足贝叶斯一致性，需要做序列均衡或直观标准等精炼。

政府—企业子博弈：

- 规制型 Stackelberg 均衡；
- 满足激励相容和参与约束的委托代理均衡；
- 分离均衡、混同均衡或半分离均衡。

企业市场子博弈：

- 贝叶斯纳什均衡；
- 差异化 Cournot 或 Bertrand 均衡；
- 供应链网络稳定均衡。

第三方联盟：

- 联盟证明纳什均衡；
- 稳定联盟结构；
- 存在转移支付时的核心或稳定分割。

### 4.3 求解顺序

推荐逆向分解，而不是一次性枚举全部策略：

1. 给定政策、类型和联盟结构，求企业市场子博弈；
2. 给定政策和对其他企业反应的预测，求企业合规、研发和迁移选择；
3. 给定企业最佳反应，求第三方政府的对齐或加入选择；
4. 枚举或局部搜索可行的第三方联盟结构；
5. 把上述结果代回中美政府的动态博弈，求 PBE 或近似 PBE；
6. 用历史事件校准参数，做反事实和政策敏感性分析。

### 4.4 计算规模建议

第一版建议：

- 政府：2 个；
- 第三方政府：4 个，联盟结构数量仍可枚举或剪枝；
- 企业类型块：中美各 2 至 3 个；
- 第三方企业类型块：每个第三方 1 至 2 个；
- 每类企业：2 至 3 个离散类型；
- 政策行动：每个政府 8 至 12 个离散选项；
- 企业行动：每个类型 4 至 6 个离散选项；
- 时间：8 至 12 个季度。

先用离散行动和有限类型求可解释基准；确认结果后，再扩展到连续补贴、价格和研发强度。

## 5. 需要用数据校准的对象

- BIS 实体清单、EAR 规则、许可证和执法案例；
- 半导体产品、设备、材料和服务的贸易流；
- 企业收入地区分布、客户集中度、供应商集中度和资本开支；
- 管制事件前后的股价、订单、交付周期和产能布局；
- 中国国产替代、研发投入和进口替代指标；
- 荷兰、日本、韩国等第三方的政策参与和执法强度；
- 第三方政府的联盟承诺、安全合作和市场依赖指标。

模型至少应输出：

- 美国和中国的均衡管制与反制强度；
- 不同企业类型的合规、迁移、研发和退出概率；
- 第三方政府的对齐概率和稳定联盟结构；
- 市场份额、价格、贸易流、技术差距和福利；
- 对执法强度、联盟规模、替代速度和沉没成本的敏感性。

可用 2022 年、2023 年管制扩围及荷兰、日本的相关政策作为历史校准和样本外检验。

### 6.3 战略谈判参考

[facebookresearch/diplomacy_cicero](https://github.com/facebookresearch/diplomacy_cicero) 实现了带自然语言谈判的战略规划，可借鉴“语言信号 + 策略搜索 + 联盟”结构。但仓库已归档，许可证为自定义许可而非可直接套用的标准许可证，依赖较旧，适合阅读和研究，不适合作为新项目的工程底座。

## 7. 推荐技术路线

建议采用“双层实现”：

1. **理论核心层**：用 OpenSpiel 写有限期分层动态博弈；小型版本用 Gambit 做精确 Nash/PBE 校核；
2. **经济子层**：自写企业类型、供应链网络、政策工具和联盟形成模块；
3. **情景扩展层**：用 PettingZoo 包装环境，用 Mava 或 CFR 做大规模近似策略搜索；
4. **叙事与验证层**：只在需要自然语言信号、谈判或政策文本时使用 Concordia/WarAgent 类方法，并把 LLM 输出作为外生信号或候选动作，不应让 LLM 直接充当均衡求解器。

最先应完成的是一个可复现的小型模型：

- 2 个政府；
- 中美各 2 类企业；
- 2 个第三方政府；
- 第三方各 1 类企业；
- 2 个政府类型、3 个企业类型；
- 6 期；
- 离散政策和企业动作；
- 先求简化企业市场子博弈，再求 PBE 近似。

这个小模型跑通后，再增加第三方数量、联盟结构和连续政策变量。这样比先做完整 LLM 仿真更容易得到可解释、可检验的博弈论结论。
